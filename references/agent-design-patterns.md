## 1. 模型层模式

| 模式 | 说明 | 代表 | 适用 |
|---|---|---|---|
| 单一自研 | harness 与模型共进化，harness 随模型变强而变薄 | Claude Code、Codex | 模型厂 |
| 多模型聚合 | 一个订阅打包多家旗舰，用户免选择 | Perplexity、Notion AI | 应用厂，有采购议价力 |
| 双池混合 | 自研模型承接默认流量，第三方按 API 价过手 | Cursor | 有自研小模型能力的应用厂 |
| 任务分级路由 | 快模型做探索/摘要，旗舰做最终生成 | Claude Code（Haiku 做 Explore） | 所有 agent，直接降本 |

## 2. Prompt 封装模式

- **分层 XML 结构**：goal → format_rules → restrictions → query_type 路由 → output（Perplexity 七段式）。意图分类在前段流水线完成，Prompt 只把类别翻译成文体规则。
- **静态/动态分区**：稳定内容放前、会话内容放后，中间显式分界——为 prompt caching 设计，缓存命中率直接等于毛利（Claude Code 的 `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__`；Codex 全量无状态历史 + 前缀缓存工程，优化后 80–90% 命中率、输入成本降 40–55%）。
- **行为规约写进 Prompt**：工具名对用户消毒（"读文件"而非"调用 read_file"）；并行工具调用作为硬指令；输出格式法典（引用格式、文件引用带行号）。
- **克制条款**：明确"不做什么"——不主动创建文件、不超额完成、危险操作必须问。面向普通用户的产品，克制条款密度与成熟度正相关（Notion AI 半份 Prompt 在教模型别做什么）。
- **反常识条款**：让模型"先说计划/先汇报"会导致它说完就停——追求 autonomy 的 agent 应删除此类客套指令（OpenAI Codex Prompting Guide 官方结论）。
- **约束输出结构**：编辑类动作用自定义工具 + 语法约束（Codex 的 apply_patch + Lark CFG），在解码层消灭格式幻觉。

## 3. RAG 决策树

```
数据是否需要权限过滤？
├─ 是（企业多租户）→ 预建索引 + 权限元数据过滤（Notion 模式）
│                    权限继承是一票否决项，必须前置设计
└─ 否 → 查询对象是"结构关系"还是"语义内容"？
    ├─ 结构关系（谁调用谁/依赖链）→ Agentic 检索（Claude Code/Codex 模式）
    │   嵌入存的是相似性不是关系，结构问题必须让模型用工具顺着链走
    └─ 语义内容 → 语料规模与更新频率？
        ├─ 超大/高频更新（网页、代码库）→ 预建索引 + 增量同步
        │   （Cursor：AST 切块 + Merkle 树 diff + namespace 隔离）
        └─ 中小/低频 → 混合：默认 Agentic，热点语料建索引
```

**索引派关键技术要点**：按语义边界切块（tree-sitter/标题段落）而非按行数硬切；BM25 + 稠密向量混合检索（Cursor 实测混合比纯 grep 提升 23.5%）；多层重排带硬阈值，宁可重查不喂垃圾（Perplexity L1–L3，~0.7 阈值）；段落级排序优于页面级。

**Agentic 派前提**：模型足够强、工具延迟足够低、推理足够便宜。成本从预处理转移到推理 token。

**第三条路**：coding 场景用"可执行环境"替代更多检索——跑测试的结果就是 ground truth（Codex 云任务模式）。

## 4. 上下文工程模式

- **子 Agent 隔离**：重活外包到独立上下文，只回收摘要（Claude Code：Explore 用快模型只读）。
- **服务器不存原文**：云端只存向量 + 混淆路径，查询命中后客户端本地回补原文（Cursor 模式，隐私敏感场景范式答案）。
- **团队索引复用**：组织内代码库高度相似（约 92%），simhash 匹配 + 索引复制把冷启动从小时降到秒级；用内容证明防越权。
- **压缩 URL/ID**：长标识符在上下文里用短引用替代，后端解压（Notion AI）。
- **计划外化**：TodoWrite 类工具把计划写成结构化外部状态，抗"中段遗忘"。

## 5. 权限与安全模式

| 模式 | 机制 | 代表 |
|---|---|---|
| 三级沙箱 | read-only / workspace-write / full-access | Codex |
| 双闸门限流 | 短窗口（5h）+ 长窗口（周）防滥用兼做价格杠杆 | Claude Code |
| 云端默认断网 | agent 阶段网络默认关闭，域名白名单 + 限 HTTP 方法 | Codex Cloud |
| Hook 确定性拦截 | 生命周期事件挂 shell 命令，"必须永远发生的事属于 hook 不属于 prompt" | Claude Code |
| 越权防护 | 检索结果需客户端证明访问权（Merkle proof） | Cursor |

## 6. 商业化定价模式

| 模式 | 结构 | 代表 | 关键数字 |
|---|---|---|---|
| 订阅答案引擎 | Free → $20 → $200，撤广告赌信任溢价 | Perplexity | 免费层做获客漏斗 |
| 算力批发转零售 | 订阅费≈第三方模型用量池，高档位反而折扣 | Cursor | Ultra $200 得 $400 用量 |
| 模型分发渠道 | 工具不图赚钱，拉动订阅与 API 用量 | Claude Code | 官方均值 $13/人/日 |
| 全家桶钩子 | 最强功能（云任务）锁进订阅，API 不可用 | Codex | 安装即转化 |
| 升舱杠杆 | AI 捆进高档套餐而非单卖 add-on | Notion AI | AI 依赖数据密度→全员使用→不按人头单收 |

**定价通则**：五家头部全部收敛于 $20 入门 / $100–200 重度价格带；差异只在"卖什么"。定价结构即战略宣言。
